# 主题风格系统

两套相互独立的坐标：

- **主题风格**（tech / math / science / art / humanities / business）：决定品牌色和字体气质
- **明暗模式**（light / dark）：由 `[data-theme]` 控制，每套风格都必须两种都有

风格文件 `theme-*.css` 只负责覆盖品牌色；表面、文字、边框、提示框、徽章等中性令牌由 `assets/style.css` 的深色块统一提供，不需要在每个主题里重复。

## 主题分类

- **`theme-tech`** — 技术/编程类：深色代码块，蓝色系，技术感
- **`theme-math`** — 数学/理论类：纸质感，衬线字体，学术氛围
- **`theme-science`** — 科学/工程类：冷色调，数据友好，实验室感
- **`theme-art`** — 设计/艺术类：大胆渐变，高对比，现代感
- **`theme-humanities`** — 人文/语言类：温暖色调，舒适阅读
- **`theme-business`** — 商业/职场类：专业深蓝，干净利落

## 选择逻辑

根据教程主题自动判断最合适的风格：
- **纯技术类**（编程、框架、工具）→ `theme-tech`
- **理论/数学类**（算法理论、数学、统计）→ `theme-math`
- **应用科学类**（数据分析、物理、工程）→ `theme-science`
- **设计/视觉类**（UI、图形、动画）→ `theme-art`
- **人文/语言类**（语言学习、写作）→ `theme-humanities`
- **商业/管理类**（营销、管理、职场）→ `theme-business`

**跨领域判断：** 如果主题跨领域（如"Python 数据分析"），优先选择实操性更强的主题（此例选 `theme-tech`，因为重点是编程实现而非数据科学理论）。默认使用 `theme-tech`。

## 明暗两套取值

| 主题 | 浅色 `--primary` | 深色 `--primary` | 浅色 页面/卡片 | 深色 页面/卡片 |
|------|------------------|------------------|----------------|----------------|
| tech | `#007acc` | `#4da3e0` | `#f5f5f5` / `#ffffff` | `#0d1014` / `#161a21` |
| math | `#8b4513` | `#d2a06a` | `#f5f3ed` / `#fffef8` | `#14110c` / `#1d1913` |
| science | `#1976d2` | `#5eb8f7` | `#eceff1` / `#ffffff` | `#0b1013` / `#131a20` |
| art | `#c2185b` | `#ff7aa8` | `#f7f4f6` / `#ffffff` | `#110b0e` / `#1a1216` |
| humanities | `#8a5a2b` | `#d9a273` | `#f7f2ea` / `#fffdf7` | `#131010` / `#1d1815` |
| business | `#1f3a5f` | `#7fb0dd` | `#f4f6f8` / `#ffffff` | `#0b0f14` / `#121821` |

上表取值在各自背景上的对比度均已按 4.5:1 核算通过。改色时守住这条线：主色作为链接正文使用时，浅色模式下要够深，深色模式下要够亮。

**取色规则：** 深色模式的主色必须更亮、饱和度更低。直接把浅色主色搬进深色块，会得到深底深字。深色下 `--text-on-accent` 通常要反过来变成深色，因为亮色主色上的白字对比度不够。

## 写入位置

```
:root { ... }                  /* 浅色取值 */
:root[data-theme="dark"] { }   /* 深色取值 */
```

样式加载顺序固定：`prism-tomorrow` → `style.css` → `theme-*.css`。主题文件在后面，所以它能覆盖 `style.css` 里的同名令牌。

完整样板代码见 `references/assets.md`。
